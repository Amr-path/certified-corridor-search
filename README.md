# Certified Corridor Search — code, data and paper sources

Supplementary material for *Certified Corridor Search on Grid Maps* (A. Elshahed and M. K. B. Majahar Ali,
Universiti Sains Malaysia; submitted to Expert Systems with Applications).

```
code/         C++17 implementation and the Python pipeline that produced every number in Section 7
checks/       mechanical checks of the theory (exhaustive and randomised; Appendix A and B of the paper)
experiments/  provenance, run logs, per-instance records (compressed) and aggregated analyses
```

## Reproducing the experiments

Build (g++ 13.3 was used):

    g++ -O3 -std=c++17 -o ccs code/ccs.cpp

`experiments/PROVENANCE.txt` records the sha256 of `ccs.cpp` and of the binary that produced all records.
Benchmarks: the Moving AI sets (https://movingai.com/benchmarks/) placed under `bench/<set>/` as
`*.map` and `*.map.scen`; sets used: dao, bg512, sc1, random, room, street, maze (uniform cost) and
dao, sc1, wc3maps512, weighted (terrain weights). Then

    python3 code/run_all.py uniform      # 19,810 jobs -> results/uniform/<set>/<config>__<scen>.csv
    python3 code/run_all.py weighted     #  5,740 jobs -> results/weighted/...
    python3 code/analyze.py results/uniform  analysis/uniform
    python3 code/analyze.py results/weighted analysis/weighted
    python3 code/paper_tables.py <tables_dir>
    python3 code/paper_figs.py   <figures_dir>

Scripts locate data relative to the repository root (override with the environment variable `CCS_ROOT`), expecting `bench/`, `results/`, `analysis_uniform/`, `analysis_weighted/` and `results_wfls/` under it; unpack `experiments/results/*.tar.gz` into `results/{uniform,weighted}/` and copy `experiments/analysis/{uniform,weighted}` to `analysis_{uniform,weighted}/` to regenerate the tables and figures without rerunning.

Instances `0, 25, 50, ...` of every scenario file are solved (`--every 25`). Modes of `ccs`:
`astar | jps | wastar | fls | castar` (corridor A* on G_C^+) `| cjps` (JPS_C on M_C)
`| pair` (A* on M_C and JPS_C back to back) `| ccs --inner castar|cjps [--k0rel 0.25]`.
CSV columns: `id,alg,map,k,w,expanded,generated,scanned,micros,U,Phi,L,opt,rounds,extra`.

The focal-list JPS baseline (Section 7, CJPS–FLS) was run from the authors' code,
https://bitbucket.org/mcar0024/pathfinding, branch `jps-wastar-fixing`, commit `1ed64b3c`
(`code/run_wfls.py`, `code/analyze_wfls.py`; records in `experiments/results/results_wfls.tar.gz`).

## Records

`experiments/results/{uniform,weighted}/<set>.tar.gz` hold the per-instance CSVs (25,550 files);
`experiments/analysis/` the aggregated JSON and LaTeX tables; `experiments/run_*.log` the driver logs
(0 failures). Figure 1 of the paper is generated by `code/make_fig_corridor.py`.
